Untuk membuat aplikasi ini menjadi milik Anda 100% dan bisa diakses oleh guru-guru dari rumah atau sekolah, ikuti panduan ini: Langkah 1: Siapkan Database Firebase Sendiri (Gratis) Kunjungi firebase.google.com dan buat proyek baru. Buka menu Firestore Database dan buat database dalam mode "Test Mode" untuk awal. Buka menu Project Settings, lalu tambahkan aplikasi Web. Anda akan mendapatkan serangkaian kode firebaseConfig (berisi apiKey, authDomain, dll). Ganti baris kode firebaseConfig = typeof __firebase_config !== ... di dalam file HTML di atas dengan kode konfigurasi dari Firebase Anda. (Terkait Login Google): Buka menu Authentication di Firebase > Sign-in method > Aktifkan Google. Nantinya Anda bisa mengubah fungsi signInAnonymously() di kode menjadi signInWithPopup(auth, new GoogleAuthProvider()). Langkah 2: Hosting Gratis di GitHub Pages Buat akun di github.com. Buat repositori (repository) baru (misalnya dengan nama portal-guru). Masukkan kode HTML yang saya hasilkan di atas ke dalam file bernama index.html dan Upload ke repositori tersebut. Masuk ke menu Settings repositori Anda, cari menu Pages (GitHub Pages). Pada bagian Source, pilih branch main, lalu klik Save. Tunggu 1-2 menit, GitHub akan memberikan link publik aplikasi Anda (misal: https://[username].github.io/portal-guru). Link tersebut sudah bisa Anda bagikan ke rekan sesama guru dan mereka bisa mulai menggunakan aplikasi ini! Silakan coba versi live aplikasinya di layar Anda sekarang. Silakan ikuti panduan berikut berdasarkan layar yang sedang Anda lihat: Langkah 1: Buat Database Firestore Klik tombol "Create database" yang ada di tengah layar (tombol dengan garis luar kuning/oranye di gambar Anda). Pilih Lokasi Server (Location): Jika ditanya lokasi, pilih server yang paling dekat dengan Indonesia, misalnya asia-southeast2 (Jakarta) atau asia-southeast1 (Singapura), lalu klik Next. Aturan Keamanan (Security Rules): Ini SANGAT PENTING. Pilih "Start in test mode" (Mulai dalam mode pengujian). Mode ini akan mengizinkan aplikasi Anda membaca dan menyimpan data selama 30 hari ke depan tanpa harus mengatur aturan keamanan yang rumit dulu. Klik Enable atau Create. Langkah 2: Ambil Kode Konfigurasi Firebase (firebaseConfig) Setelah database selesai dimuat, Anda perlu mengambil "kunci" agar kode HTML kita bisa terhubung ke database ini. Di menu sebelah kiri atas, di samping tulisan "Project Overview", klik ikon Gerigi ⚙️, lalu pilih "Project settings". Scroll (gulir) halaman ke bawah sampai Anda menemukan bagian "Your apps". Klik ikon bergambar (ikon Web) untuk mendaftarkan aplikasi web Anda. Beri nama aplikasi (misalnya: "Portal Guru Web"), biarkan kotak Firebase Hosting kosong dulu, lalu klik Register app. Nanti akan muncul sebuah kotak berisi kode JavaScript. Cari bagian kode yang bentuknya seperti ini dan Copy (Salin): JavaScript const firebaseConfig = { apiKey: "AIzaSyB...", authDomain: "tes-apk-jurnal.firebaseapp.com", projectId: "tes-apk-jurnal", storageBucket: "tes-apk-jurnal.appspot.com", messagingSenderId: "123456789", appId: "1:12345:web:abcde" }; Klik "Continue to console". Langkah 3: Aktifkan Login (Authentication) Agar guru bisa masuk ke aplikasi, kita harus mengaktifkan sistem akunnya. Di menu sebelah kiri Firebase Anda, cari dan klik menu "Authentication". Klik tombol "Get started". Di tab "Sign-in method", aktifkan "Anonymous" (Paling bawah). Ini penting agar guru bisa langsung mencoba masuk sementara tanpa harus repot mengatur akun Google dulu. (Nanti jika sudah mantap, Anda bisa mengaktifkan opsi "Google" di halaman ini).
